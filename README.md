# LLM-as-a-Judge-and-DPO

Dissertation Goal:

The aim of this MSc dissertation is to assess the ability of large LLMs to judge the harmfulness of output from smaller LLMs. In addition, direct preference optimisation (DPO) will be performed using the annotations generated as part of the study. (Due for completion in May 2027).
